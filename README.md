# 国会図書館件名標目タガー (NDLSH Tagger)


テキスト中の**国立国会図書館件名標目（NDLSH・参照形含む）**をブラウザ上で高速検出し、標目形やNDC分類記号の提示、MARC・目録システム向けの一括コピーができる静的Webアプリケーションです。

2012年に東京大学情報基盤センター「図書系職員のためのアプリケーション開発講習会」の成果物として公開されたオリジナル版（[NDLSH_tagger](https://mbc.dl.itc.u-tokyo.ac.jp/NDLSH_tagger/)）をベースに、サーバー不要で完全クライアントサイド実行可能な静的Webサイト（GitHub Pages対応）として再設計・モダンリニューアルしました。

---

## ✨ 主な特徴

- ⚡ **完全クライアントサイド実行 (サーバーレス)**
  - 外部サーバーへのテキスト送信やCGI処理は一切不要。
  - すべてブラウザ内のメモリ上で高速マッチング（Trie木 / 前方一致木）を行うため、長文でもミリ秒単位で瞬時にタグ付けされます。
  - GitHub Pages などの静的ホスティングでそのまま公開可能です。
- 📚 **最新の Web NDL Authorities オープンデータ連動**
  - 国立国会図書館の「Web NDL Authorities（国立国会図書館典拠データ検索・提供サービス）」の普通件名典拠（約20,800標目＋約35,200同義語）に対応。
  - 標目形はもちろん、同義語・別名（参照形・USE/UF）も自動で正規化・検出。
- 🎯 **高精度な最長一致＆単語境界判定**
  - ブラウザ標準の国際化API（`Intl.Segmenter`）による単語境界チェックを搭載。
  - 「1文字標目（本, 法, 絵, 道 など）の除外/許可」オプションを装備し、文脈に応じた最適なタグ付けを実現。
- 🏷️ **モダン＆クラシックのデュアル表示モード**
  - **モダン表示**: タグ風バッジと美しいポップオーバーツールチップ（標目形、読み、NDC/NDLC分類、上位語、関連語、注記、Web NDL Authorities直リンク、NDLサーチ所蔵検索リンク）。
  - **クラシック表示**: 2012年のオリジナル版のデザイン（`[標目]` 青字スタイル）を忠実に再現。
- 📋 **目録担当者のための強力なコピー＆エクスポート支援**
  - 「標目のみコピー（改行区切り）」
  - 「スラッシュ区切りコピー（MARC/NACSIS形式）」
  - 「標目＋NDC分類記号コピー」
  - 「検出結果のCSVエクスポート」
- 🔍 **NDLSH辞書クイック検索機能**
  - テキストのタグ付けだけでなく、55,000語以上の件名標目・同義語・NDC分類をリアルタイムに辞書引き・逆引きできます。
- 🌓 **ダークモード対応＆レスポンシブデザイン**
  - OS設定との自動連動および手動切替。PC、タブレット、スマートフォンに対応。

## 💻 ローカルでの実行・テスト

静的Webサイトのため、任意のローカルHTTPサーバーで即座に動作します。

```bash
# Python 3 の組み込みサーバーを使用する場合
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

---

## 🔄 データの更新方法

国立国会図書館の最新の件名標目データ（日次更新）を取得して `data/ndlsh.json` を更新するには、以下のスクリプトを実行します。

```bash
# NDL公式から最新TSVを自動ダウンロードしてJSONを再構築
python scripts/update_data.py
```

手動でダウンロードしたTSVファイルからビルドする場合：

```bash
python scripts/build_data.py
```
